# Juridisch Documentensysteem — EHO Consultancy

## Overzicht

Dit systeem bevat alle juridische templates en risicoprofielen voor EHO Consultancy (eenmanszaak), gespecialiseerd in IT, automation, CRM en operations dienstverlening.

## Structuur

```
juridisch/
├── README.md                              # Dit bestand
├── algemene-voorwaarden.md                # Algemene Voorwaarden EHO Consultancy
├── templates/
│   ├── dienstverleningsovereenkomst.md    # Template per klant
│   ├── sla.md                             # Service Level Agreement template
│   └── verwerkersovereenkomst-dpa.md      # Data Processing Agreement template
└── klanten/
    ├── risicoprofielen.md                 # Risicoprofielen per klantcategorie
    └── klantenlijst.md                    # Volledige klantenlijst met classificatie
```

## Gebruik

1. **Nieuwe klant?** → Check `klanten/risicoprofielen.md` voor de juiste categorie
2. **Contract nodig?** → Gebruik `templates/dienstverleningsovereenkomst.md` als basis
3. **SLA afspreken?** → Gebruik `templates/sla.md` (alleen indien expliciet overeengekomen)
4. **Persoonsgegevens?** → Gebruik `templates/verwerkersovereenkomst-dpa.md`
5. **Altijd:** Verwijs naar `algemene-voorwaarden.md` in elk contract

## Belangrijk

- Alle documenten zijn templates — pas aan per klant
- Velden tussen `[vierkante haken]` moeten worden ingevuld
- Laat bij twijfel een jurist meekijken
- Algemene Voorwaarden altijd meesturen bij offertes en facturen
