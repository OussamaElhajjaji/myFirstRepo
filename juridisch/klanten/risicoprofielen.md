## Categorie 1: Batterij Installateurs (B2C)

**Klanten:** Dakprofijt, Batterijprofijt, BatteriQ, VoltaGrid, Solaar, Verduurzaam Experts, Batterijnet, Thuisopslagbatterij.nl

### 1. Risiconiveau: **HOOG**

### 2. Belangrijkste juridische risico's
- Verwerking van persoonsgegevens van consumenten (B2C = strenger AVG-toezicht)
- Afhankelijkheid van jouw systemen voor hun dagelijkse operatie (CRM, leadflow, planning)
- Claimsrisico bij dataverlies of systeemuitval (consumentenklachten worden doorgeschoven)
- Energiesector = gereguleerde markt, compliance-eisen
- Meerdere klanten op vergelijkbaar systeem = besmettingsrisico bij fouten

### 3. Benodigde contracten
- Dienstverleningsovereenkomst **verplicht**
- Verwerkersovereenkomst (DPA) **verplicht**
- Algemene Voorwaarden **verplicht**
- SLA **aanbevolen** (gezien bedrijfskritische aard)

### 4. SLA verplicht?
**Ja, sterk aanbevolen.** Systemen zijn vaak kritisch voor hun dagelijkse operatie.

### 5. DPA nodig?
**Ja, verplicht.** Consumentengegevens (naam, adres, e-mail, telefoon, energiegegevens).

### 6. Aansprakelijkheid zwaar?
**Ja.** Max factuurwaarde laatste 3 maanden. Uitdrukkelijk geen indirecte schade, geen gederfde winst, geen consumentenclaims.

### 7. IP risico
**Middel tot hoog.** Workflows, automations en CRM-inrichtingen die je bouwt zijn waardevol. Zorg dat IP bij jou blijft. Klant krijgt gebruiksrecht, geen eigendom.

### 8. Betaalstructuur advies
- Projecten: 50% vooraf, 50% bij oplevering
- Abonnementen: maandelijks vooraf
- Meerwerk: vooraf akkoord, maandelijks factureren

### 9. Stop/exit risico
**Hoog.** Als ze stoppen, moeten systemen netjes worden overgedragen of afgesloten. Data-export binnen 30 dagen, daarna verwijderen. Migratie = meerwerk.

### 10. Absoluut afdekken
- [x] DPA met duidelijke rolverdeling
- [x] Geen resultaatsverplichting
- [x] Geen aansprakelijkheid voor systemen derden
- [x] Geen uptime garantie (tenzij SLA)
- [x] IP blijft bij jou
- [x] Exit-clausule met duidelijke termijnen
- [x] Betaling vooraf

## Categorie 2: Energieleveranciers

**Klanten:** PulsePower, Clean Energy

### 1. Risiconiveau: **HOOG**

### 2. Belangrijkste juridische risico's
- Grote volumes persoonsgegevens (klantbestanden energieleverancier)
- Gereguleerde sector met hoge compliance-eisen (ACM, AP)
- Bedrijfskritische systemen (CRM, billing, klantenservice)
- Hogere verwachtingen qua beschikbaarheid en betrouwbaarheid
- Risico op hoge claims bij fouten (mis-facturatie, datalekken)

### 3. Benodigde contracten
- Dienstverleningsovereenkomst **verplicht**
- Verwerkersovereenkomst (DPA) **verplicht**
- Algemene Voorwaarden **verplicht**
- SLA **verplicht**

### 4. SLA verplicht?
**Ja.** Operationeel kritisch.

### 5. DPA nodig?
**Ja, verplicht.** Grote hoeveelheid consumentengegevens, mogelijk bijzondere gegevens (energieverbruik).

### 6. Aansprakelijkheid zwaar?
**Ja, strak afdekken.** Max factuurwaarde, geen indirecte schade, korte vervaltermijn. Overweeg beroepsaansprakelijkheidsverzekering.

### 7. IP risico
**Hoog.** Complexe integraties en automations. IP absoluut bij jou houden.

### 8. Betaalstructuur advies
- Maandelijks vooraf voor managed services
- Projecten: 40% vooraf, 30% halverwege, 30% bij oplevering
- Meerwerk: maandelijks achteraf met gedetailleerde urenadministratie

### 9. Stop/exit risico
**Zeer hoog.** Complexe systemen, veel data. Langere exit-periode nodig. Migratie-ondersteuning als meerwerk.

### 10. Absoluut afdekken
- [x] DPA met gedetailleerde subverwerkers-lijst
- [x] Strakke aansprakelijkheidsbeperking
- [x] Geen verantwoordelijkheid voor compliance-verplichtingen van de klant
- [x] Duidelijke scope — alles erbuiten is meerwerk
- [x] IP bescherming
- [x] Opschortingsrecht bij wanbetaling
- [x] Exit-clausule met minimaal 60 dagen transitie

## Categorie 3: B2B Batterij / Energie Opslag

**Klanten:** Smart Power Hub, Golden Triangle BV, Hi-Tronic BV

### 1. Risiconiveau: **MIDDEL**

### 2. Belangrijkste juridische risico's
- B2B context = minder AVG-risico (minder consumentengegevens)
- Wel bedrijfskritische operatie mogelijk
- Technische integraties met industriële systemen
- IP-risico bij maatwerk

### 3. Benodigde contracten
- Dienstverleningsovereenkomst **verplicht**
- Verwerkersovereenkomst (DPA) **indien persoonsgegevens**
- Algemene Voorwaarden **verplicht**
- SLA **optioneel** (afhankelijk van scope)

### 4. SLA verplicht?
**Optioneel.** Hangt af van of dienst kritisch is voor hun operatie.

### 5. DPA nodig?
**Alleen als je persoonsgegevens verwerkt** (bijv. contactgegevens medewerkers, klantdata).

### 6. Aansprakelijkheid zwaar?
**Middel.** Standaard factuurwaarde-cap voldoende. Geen indirecte schade.

### 7. IP risico
**Middel.** Bij maatwerk IP goed afbakenen. Standaard: IP bij jou.

### 8. Betaalstructuur advies
- Projecten: 50% vooraf, 50% bij oplevering
- Uurtarief: maandelijks achteraf

### 9. Stop/exit risico
**Middel.** Standaard exit-clausule volstaat.

### 10. Absoluut afdekken
- [x] Duidelijke scope-afbakening
- [x] IP-clausule
- [x] Geen resultaatsverplichting
- [x] Meerwerk-clausule

## Categorie 4: Lead Generatie Platforms

**Klanten:** Thuisopslagbatterij.nl, Zakelijkopslagadvies.nl, VoltaGrid (lead campagnes)

### 1. Risiconiveau: **HOOG**

### 2. Belangrijkste juridische risico's
- Grote volumes persoonsgegevens (leads = consumenten)
- AVG-compliance cruciaal (opt-in, verwerkingsgrondslag, bewaartermijnen)
- Onduidelijkheid over verwerkingsrolverdeling (ben jij verwerker of gezamenlijk verantwoordelijke?)
- Risico op AP-boetes bij onjuiste verwerking
- Leadkwaliteit-claims

### 3. Benodigde contracten
- Dienstverleningsovereenkomst **verplicht**
- Verwerkersovereenkomst (DPA) **verplicht**
- Algemene Voorwaarden **verplicht**
- Privacybeleid op websites **verplicht**

### 4. SLA verplicht?
**Nee, tenzij je beschikbaarheid van het platform garandeert.** Best effort volstaat.

### 5. DPA nodig?
**Ja, absoluut verplicht.** Massale verwerking consumentengegevens.

### 6. Aansprakelijkheid zwaar?
**Ja.** Expliciet geen aansprakelijkheid voor leadkwaliteit, conversieratio's of omzet. Geen resultaatsverplichting.

### 7. IP risico
**Hoog.** Websites, funnels, automations zijn jouw IP. Bewaken.

### 8. Betaalstructuur advies
- Maandelijks vooraf (abonnement)
- Geen pay-per-lead model zonder cap

### 9. Stop/exit risico
**Hoog.** Domeinnamen, content, leads — wie is eigenaar? Duidelijk vastleggen.

### 10. Absoluut afdekken
- [x] Rolverdeling AVG (verwerker vs. verantwoordelijke)
- [x] Geen resultaatsverplichting (leads, conversie)
- [x] IP op websites en funnels bij jou
- [x] Domeinnaameigendom vastleggen
- [x] DPA met duidelijke bewaartermijnen
- [x] Disclaimer leadkwaliteit

## Categorie 5: Service / Callcenter

**Klanten:** Externe sales teams, Klantenservice teams, QC teams, Backoffice teams

### 1. Risiconiveau: **MIDDEL tot HOOG**

### 2. Belangrijkste juridische risico's
- Persoonsgegevens van eindklanten (consumenten)
- Kwaliteitsclaims (callcenter performance)
- Afhankelijkheid van jouw CRM/systemen
- Personeelsgerelateerde risico's (schijnzelfstandigheid als je mensen aanstuurt)

### 3. Benodigde contracten
- Dienstverleningsovereenkomst **verplicht**
- Verwerkersovereenkomst (DPA) **verplicht**
- Algemene Voorwaarden **verplicht**
- SLA **aanbevolen**

### 4. SLA verplicht?
**Aanbevolen.** Duidelijke afspraken over responstijden en bereikbaarheid.

### 5. DPA nodig?
**Ja.** Callcenter verwerkt persoonsgegevens van eindklanten.

### 6. Aansprakelijkheid zwaar?
**Middel tot hoog.** Geen aansprakelijkheid voor resultaten van sales/service teams. Geen aansprakelijkheid voor indirecte schade.

### 7. IP risico
**Middel.** Scripts, workflows, trainingsmateriaal — IP bij jou.

### 8. Betaalstructuur advies
- Maandelijks vooraf
- Eventueel per seat/agent model

### 9. Stop/exit risico
**Middel.** Transitie van operatie naar andere partij kost tijd. Minimaal 30 dagen opzegtermijn.

### 10. Absoluut afdekken
- [x] Geen resultaatsverplichting (sales targets, klanttevredenheid)
- [x] DPA voor eindklantgegevens
- [x] Geen schijnzelfstandigheid (als je teams aanstuurt)
- [x] Duidelijke scope: IT/systemen vs. operationele aansturing

## Categorie 6: IT / Software Klanten

**Klanten:** CRM klanten, Portal klanten, API integratie klanten, Automation klanten

### 1. Risiconiveau: **MIDDEL**

### 2. Belangrijkste juridische risico's
- Technische afhankelijkheid
- IP op maatwerk
- Derden-systeem risico (API's, platforms)
- Dataverlies bij fouten

### 3. Benodigde contracten
- Dienstverleningsovereenkomst **verplicht**
- Verwerkersovereenkomst (DPA) **indien persoonsgegevens**
- Algemene Voorwaarden **verplicht**
- SLA **optioneel**

### 4. SLA verplicht?
**Optioneel.** Alleen bij managed services of doorlopend beheer.

### 5. DPA nodig?
**Afhankelijk.** Ja als je toegang hebt tot persoonsgegevens in hun systemen.

### 6. Aansprakelijkheid zwaar?
**Middel.** Standaard cap. Expliciet geen aansprakelijkheid voor derden-systemen en API-wijzigingen.

### 7. IP risico
**Hoog.** Code, scripts, automations, templates — IP bij jou. Gebruiksrecht voor klant.

### 8. Betaalstructuur advies
- Projecten: 50% vooraf, 50% bij oplevering
- Abonnementen: maandelijks vooraf
- Uurtarief: maandelijks achteraf

### 9. Stop/exit risico
**Middel.** Code-overdracht regelen. Documentatie als meerwerk.

### 10. Absoluut afdekken
- [x] IP-clausule (eigendom bij jou)
- [x] Derden-systeem disclaimer
- [x] API-wijziging disclaimer
- [x] Geen uptime garantie
- [x] Meerwerk bij wijzigingen door derden
- [x] Geen resultaatsverplichting
